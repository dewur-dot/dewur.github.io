세계 평화를 위해 결혼해주세요 — 모바일 확인용 웹 배포본
버전: 2026-09-30

1. 휴대폰에서 여는 방법
ZIP 압축을 풀고, index.html이 들어 있는 폴더의 내용 전체를 정적 웹 호스팅에 업로드하세요.
배포 시작 파일은 최상위 index.html입니다. 빌드 명령과 별도 서버/API 설정은 필요 없습니다.
발급받은 웹 주소를 휴대폰 브라우저에서 열면 됩니다. 세로 화면을 기준으로 만들었습니다.
호스팅에서 압축 업로드를 지원한다면 ZIP을 그대로 업로드할 수 있습니다.

2. 포함된 화면
- 메인 게임: /index.html
- 마왕 표정·자세 미리보기: /demon-expressions/index.html
- 메인 메뉴의 마왕 루트 미리보기, 효과 미리보기

3. 조작
도입부는 화면을 누르면 메인 메뉴로 건너뜁니다.
대화는 화면을 눌러 진행하며, 선택지가 나오면 선택지를 누릅니다.
자동넘기기, 되돌리기, 이어하기 기능이 포함되어 있습니다.

4. 저장
진행 상태는 접속한 기기의 브라우저에 저장됩니다.
PC의 저장 데이터가 휴대폰으로 자동으로 옮겨지지는 않습니다.
브라우저 데이터 삭제, 다른 브라우저 사용, 배포 주소 변경 시 기존 저장이 보이지 않을 수 있습니다.

5. 파일 전달 시
index.html 한 파일만 보내지 말고 폴더 전체를 올리세요. 이미지와 스크립트의 상대 경로가 필요합니다.
휴대폰 파일 앱에서 ZIP 안의 HTML을 바로 여는 방식은 정식 실행 방식이 아닙니다.
웹 호스팅에 올린 주소로 접속하세요. 이 ZIP 자체는 웹 주소나 APK/IPA가 아닙니다.

이 배포본은 현재 작업 시점의 스냅샷입니다. 이후 수정은 새 배포본을 만들어 다시 업로드해야 합니다.
실제 휴대폰 기기에서의 구동 확인은 아직 하지 않았습니다.
